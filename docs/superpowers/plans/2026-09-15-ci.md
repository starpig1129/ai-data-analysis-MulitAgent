> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add GitHub Actions CI (ruff, mypy, pytest on 3.10/3.13, pip-audit, CodeQL, Dependabot) to DATAGEN and clean the codebase so every check passes on the first run.

**Files:**

- Consumes: `MCPManager(config_path: str | Path | None)`, `async MCPManager.connect(server_name: str) -> bool` (existing).

    tmp_path: Path, monkeypatch: pytest.MonkeyPatch

    """If logs/mcp_servers.log cannot be created, server stderr goes to sys.stderr."""
    config_path = tmp_path / "mcp.yaml"

        "servers:\n  demo:\n    command: echo\n    args: []\n", encoding="utf-8"

Nothing in the repo used the package-level names (checked with `grep -rn "from src.core import\|from ..core import\|from .core import"`).

**Bug:** `src/core/__init__.py` eagerly imports every core module, including `workflow`, which imports `src.agents.factory`, which imports every agent. So importing any small `src.core.*` module (e.g. `src.core.schemas`) loads the whole agent graph. Importing `src.agents.code_agent`, `src.agents.process_agent` or `src.agents.factory` first, in a fresh interpreter, therefore fails:
`code_agent` → `from ..core.schemas import ...` → `src/core/__init__.py` → `.workflow` → `..agents.factory` → `from .code_agent import CodeAgent` (still half-initialized) → `ImportError ... (most likely due to a circular import)`. The app does not hit it only because `main.py` enters through `src.system`. Decision (maintainer, 2026-09-15): empty the package init instead of making it lazy; nothing uses the re-exports.

- [ ] **Step 1: Write the failing test** — create `tests/test_imports.py`:

```python
"""Smoke test: every module under src/ imports on its own in a fresh interpreter.

Each module is imported in a separate process, so the result does not depend
on which modules happened to be imported earlier. That catches circular
imports the application's usual import order hides, and, since test coverage
is low, also guards against removed or broken imports.
"""

import subprocess
import sys
from pathlib import Path

import pytest

REPOSITORY_ROOT = Path(__file__).resolve().parents[1]
SRC_DIRECTORY = REPOSITORY_ROOT / "src"
# Below pytest-timeout's 60 s so a hung import fails with a clear TimeoutExpired.
IMPORT_TIMEOUT_SECONDS = 50


def _module_name(path: Path) -> str:
    """Converts a source file path under src/ into its dotted module name.

    Args:
        path: Path to a ``.py`` file under ``SRC_DIRECTORY``.

    Returns:
        Dotted module name, e.g. ``src.core.router`` or ``src.core`` for
        ``src/core/__init__.py``.
    """
    relative = path.relative_to(REPOSITORY_ROOT).with_suffix("")
    parts = relative.parts[:-1] if relative.name == "__init__" else relative.parts
    return ".".join(parts)


SRC_MODULE_NAMES = sorted(_module_name(path) for path in SRC_DIRECTORY.rglob("*.py"))


@pytest.mark.parametrize("module_name", SRC_MODULE_NAMES)
def test_module_imports_in_fresh_interpreter(module_name: str) -> None:
    """Importing the module first, in a new interpreter, does not raise."""
    completed = subprocess.run(
        [sys.executable, "-c", f"import {module_name}"],
        capture_output=True,
        text=True,
        timeout=IMPORT_TIMEOUT_SECONDS,
        cwd=REPOSITORY_ROOT,
    )
    assert completed.returncode == 0, completed.stderr
```

The child process inherits the environment (including `CONFIG_DIRECTORY` if you set it) and runs from the repository root, so `src` resolves the same way it does under pytest.

  contents: read

      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1

          persist-credentials: false

      # `paths` filter would leave unrelated PRs waiting on a check that never
      # starts. PRs that do not touch requirements files exit here.
      - name: Detect dependency changes
        id: changes
        env:
          EVENT_NAME: ${{ github.event_name }}
          BASE_SHA: ${{ github.event.pull_request.base.sha }}
          HEAD_SHA: ${{ github.event.pull_request.head.sha }}
        run: |
          if [ "$EVENT_NAME" != "pull_request" ]; then
            echo "audit=true" >> "$GITHUB_OUTPUT"
          elif git diff --name-only "$BASE_SHA...$HEAD_SHA" | grep -E '^requirements.*\.txt$'; then
            echo "audit=true" >> "$GITHUB_OUTPUT"
          else
            echo "audit=false" >> "$GITHUB_OUTPUT"
            echo "No requirements changes in this pull request; skipping audit."
          fi
      - uses: astral-sh/setup-uv@bec219d24cd3e171d82865faccec33120bb574f4 # v10.1.0
        if: steps.changes.outputs.audit == 'true'
        with:
          python-version: "3.13"
          activate-environment: true
          enable-cache: true
          cache-dependency-glob: "requirements*.txt"
      - name: Install pip-audit
        if: steps.changes.outputs.audit == 'true'

      - name: Audit requirements
        if: steps.changes.outputs.audit == 'true'
